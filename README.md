## What's in a Real Techniques brush set

Real Techniques started in 2011, founded by sisters Sam and Nic Chapman, who were makeup artists and YouTube creators before that was a normal career path. The pitch from day one was pro-style tools at drugstore prices, and that's still roughly the positioning.

The practical details that matter when you're comparing sets:

- **Synthetic bristles only.** Custom-cut, described by the brand as UltraPlush. Nothing on the line uses animal hair.
- **Vegan and cruelty-free across the range**, latex-free too, which is worth knowing if you react to latex.
- **Extended aluminium ferrules** and lightweight handles, so the brushes don't feel like toys.
- **Brushes are cut for a specific step**, not generic. A blush brush is called a blush brush, and increasingly the dual-ended ones have a colour crystal marking which end is for cream and which is for powder.

The Kelli Anne Sewell collaboration is the most recent big drop, and it's the part of the range with the clearest purpose-built design. Sewell said in coverage of the launch that she wanted the brushes to be "educational and helpful for those overwhelmed by choosing brushes." Whether that lands depends on whether you want instructions printed on your tools, but it does make the sets easier to buy blind.

## Which set actually fits

**Total beginner, no brushes at all:** the Everyday Essentials set at $20. Five tools that cover base, crease, blush and setting, plus the Miracle Complexion Sponge. It's the set the brand treats as the entry point, and the Artists Essentials Set is explicitly positioned by Real Techniques as "the next step after Everyday Essentials."

**Beginner who wants to do it properly once:** the Light Layers Base set at $38. Marie Claire's reviewer, who tested the Kelli Anne collection, said plainly that if you've never used brushes, start with the Base set — you get a skin prep brush, foundation brush, concealer brush and a bag, and the bag matters more than you'd think if you travel. The same review calls the Premium set their personal favourite and notes "seven brushes for $65 is unheard of."

**Already own the basics and want a full face:** Light Layers Premium at $65. It adds blush and highlighter, bronzer, contour and lip brushes to the Base contents. If you already have a foundation brush you like, that $27 step up over the Base set is buying four tools you don't have rather than replacing ones you do.

**Eye-focused:** Kelli Anne Everything Eye at $25 works out at about $5 a brush, which is the cheapest per-tool maths in the range. The Eye Shade + Blend set at $14 if you only need the two core shapes.

**Just want a sponge and a couple of tools:** the Makeupsaver trio at $20 or the Precision Perfection duo at $16.

## The same set costs different amounts at different retailers

The Everyday Essentials set is $20 at Ulta. Sephora's Singapore site lists the same set at $38.00. That's partly currency and partly regional pricing, but it's the clearest illustration of the point: there is no single "Real Techniques brush set price."

The Level Up set is $30 at Editorialist and $31.45 at iHerb. Small gap, but it's there. The Kelli Anne Premium set is $65 pretty much everywhere, which suggests the collaboration sets are price-locked in a way the core range isn't.

Add sales on top and the spread widens: a $25 set on sale at $17.50 is a 30% swing, which is bigger than any cashback rate you'll find.

## Does the cashback actually arrive?

Yes, but not instantly, and the delay is structural rather than a ShopBack quirk.

Cashback appears as **Pending** first, usually within 48 hours, then flips to **Confirmed** after the retailer's return window closes. For most retailers that's 30 to 90 days. Once it's confirmed it's a standing balance with no deadline to withdraw, and it pays out as real money — in the US that's PayPal or ACH, not points or store credit. A one-star pattern in App Store reviews is exactly this wait: people expecting a 48-hour payout and getting a month. Read the terms with that in mind.
